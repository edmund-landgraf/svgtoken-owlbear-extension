# Token fonts

These six additional fonts are bundled from [Google Fonts](https://fonts.google.com/)
and are distributed under the SIL Open Font License 1.1:

- [Bangers](https://github.com/google/fonts/tree/main/ofl/bangers)
- [Oswald](https://github.com/google/fonts/tree/main/ofl/oswald)
- [Roboto Condensed](https://github.com/google/fonts/tree/main/ofl/robotocondensed)
- [Uncial Antiqua](https://github.com/google/fonts/tree/main/ofl/uncialantiqua)
- [Rye](https://github.com/google/fonts/tree/main/ofl/rye)
- [Pirata One](https://github.com/google/fonts/tree/main/ofl/pirataone)

The original Cinzel Decorative asset is bundled alongside them. The font files
are embedded into generated SVGs when selected so tokens render consistently
even when the host machine does not have the font installed.
